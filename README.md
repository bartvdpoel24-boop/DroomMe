# DroomMe

DroomMe - een applicatie voor dromen

## Beschrijving

Een eenvoudige webapplicatie om je dromen bij te houden. Sla titels, beschrijvingen en datums op in je browser (localStorage).

## Gebruik

Open `index.html` in je browser om de app te starten.

## Bestanden

- `index.html`: De hoofdpagina
- `style.css`: Styling
- `script.js`: Functionaliteit voor opslaan en weergeven van dromen

Gemaakt met Grok.

# DroomMe - Droomjournaal

Persoonlijk droomjournaal voor het bijhouden van dromen.

## Functies

**Must-have**
- Droom opschrijven met datum & tijd
- Overzicht van alle dromen, gesorteerd op datum (nieuwste eerst)
- Zoekfunctie in titel, beschrijving en tags

**Nice-to-have**
- Stemmingsscore (1-5)
- Tag-systeem (suggesties + vrije invoer)
- Analyse van veelvoorkomende woorden en tags
- Ochtendherinnering via browsernotificatie (demo)

## Gebruik

1. Open `index.html` in een moderne browser (of host de bestanden statisch).
2. Vul een droom in en sla op. Data wordt opgeslagen in localStorage van je browser.
3. Zoek, bekijk, verwijder en analyseer je dromen.

## Tech

- Pure HTML + CSS + vanilla JavaScript
- localStorage (geen backend of build-stap nodig)
- UI volledig in het Nederlands

## Privacy

Alle data blijft lokaal in je browser. De repository is momenteel publiek; zet hem privé in de GitHub-instellingen als je dat wilt.
